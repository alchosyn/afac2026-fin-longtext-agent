# 需求清单流程 v2、ReAct + 清单 + 遮蔽 vs ReAct（6 道新题）

同一模型（qwen3.6-plus，温度 0，思考模式关闭），每道题每种做法各跑一次。这 6 道题此前都没有跑过，流程也没有按它们调过。标准答案是我们按原文和计算定的，依据见 flows/compare_plan_v2.py 文件头。

ReAct：选择题用 react_relevance.py --mask none（原文全文一直留在上下文），计算题用 react_compact.py 默认模式（模型引用过的块保留全文，其余换成占位符）。“模型调用”对 ReAct 是轮数（每轮重发整段对话），对清单流程是单次调用的次数（上下文由代码重新拼）。

ReAct + 清单 + 遮蔽（react_plan.py）：模型每步自己选工具（plan / search / fill / compute），每步的上下文是代码按状态拼的快照，fill 判为不相关或已取完值的原文移出上下文。它带着清单流程 v2 之后的两处修正（计算题答案部分由代码从题面定；ready 只看数据够不够），并在这 6 道题上改过两处代码问题（工具参数的形状、跨条目的摘录核对），所以对它来说这 6 道题不算全新。
